# Dominic Morissette

Portfolio statique en page unique, conçu pour GitHub Pages.

## Aperçu local

Ouvrir `index.html` directement ou lancer un serveur statique local.

## Publication sur GitHub Pages

Publier la branche principale depuis la racine du dépôt dans les réglages GitHub Pages. Tous les chemins sont relatifs et aucune étape de compilation n'est requise.

Les images actuelles servent uniquement à valider la direction visuelle. Remplacer les fichiers de `assets/images` par les images finales en conservant les noms, ou mettre à jour les chemins dans `index.html` et `script.js`.
